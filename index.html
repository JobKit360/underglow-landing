How it works

Build, test, approve. All in one app.

Ask for a change

Tell an agent what to build or fix, in plain words. It works on your project, on your computer.

Get a test link

When it is done, you get a link. It opens in the browser built into UnderGlow, so there is nothing else to open or set up.

Approve or deny

Click around and try it. If it works, approve it. If not, send it back with a note and the agent fixes it.
