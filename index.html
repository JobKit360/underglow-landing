Build software with AI agents. All in one workspace.

UnderGlow runs agents and bots on your own PC, with a live workflow, a map of your code, a built-in browser, an optional Linux test box and a shared roadmap in a single window.

What it does

Everything an agent team needs, in one window

Give agents a job and follow the work in one place, instead of juggling terminals, browser tabs and notes.

Agents and bots at work

Give an agent a job in plain words. It reads, edits and tests inside your project folder, and its roadmap card moves as it goes.

  • One chat per agent or bot
  • See each step it takes
  • Stop or steer it any time

Your workflow, live

Follow a change from your agents to a test build and on to your live site. Each step shows whether it is idle, reading, working or needs you, and you hold the gate.

  • Plain-language steps
  • Approve or hold back with one tap
  • Click a step to see what it does

A map of your code

Your files and folders as a floating network. Watch an agent read (blue) and edit (yellow) as it moves through the project.

  • See how files connect
  • Spot where work is happening
  • Hover any dot to see its file

An optional Linux test box

An optional add-on: each agent gets its own Linux desktop to install tools, run tests and open a browser, away from the rest of your PC.

  • Off until you add it
  • Watch its screen inside UnderGlow
  • Own folder and ports for each agent

A roadmap you share with your agents

A simple board: To do, In progress, Waiting test and Complete. Agents add tasks and move them as they work.

  • Cards follow the agent doing them
  • Click or drag to move things yourself
  • Always see what is next

Check in from your phone

Open your PC's UnderGlow from your phone's browser, on your Wi-Fi or privately over Tailscale. A badge tells you if the connection is secure.

  • Same account, same app
  • Files stay on your PC
  • Secure-connection badge

Workflow graph

Code map

Open your project's website right inside UnderGlow while an agent works on it. No separate server to set up.

Use it from anywhere

Your PC does the work. Any screen can watch.

Run UnderGlow on one computer and open it from a second computer or your phone's browser on the same Wi-Fi, or privately over Tailscale (a free third-party tool, optional). You sign in with the same account, and your files stay on the host PC.

Good to know

  • Runs on Windows 10 and 11 (early beta)
  • Agents use your own Claude account through Claude Code
  • Work stays in the folders you choose
  • Linux box and Android emulator are optional add-ons

Beta status

  • Features and screens still change often
  • Phone use is a browser view of your PC, not a separate app
  • Agents can make mistakes: check their work before you ship it
  • The installer is not code-signed yet, so Windows may warn you
