What it does

Five agents. One screen. Zero confusion.

Give each agent a job and see them all working at once. No more hunting through terminals to find out who is doing what.

Every agent, one screen

Each agent gets its own chat, side by side. See what every one is doing right now, step in when you need to, and stop or redirect any of them in a click.

  • One chat per agent, all visible
  • See each step as it happens
  • Stop or steer any agent

Add a gate wherever you want one

Lay out your own steps, from your agents to a test version to your live site, and put a gate on any of them that waits for your yes before anything moves on. Or use none. It is your workflow.

  • Add or remove gates any time
  • Approve or hold back with one tap
  • Click a step to see what it does

A map of your code

Your project appears as a web of connected files. Watch agents read (blue) and change (yellow) things as they move, so you know what was touched and where.

  • See how the code connects
  • Spot where work is happening
  • Hover any dot to see its file

Every agent gets its own machine

Each agent has its own machine in the cloud. It can run code, open a browser, test your app and show you its screen, all in its own separate space.

  • Built in, nothing to set up
  • Watch its screen inside UnderGlow
  • Safe to try risky things

A to-do board your agents keep updated

A simple board with To do, In progress, Waiting test and Complete. Agents add tasks and move them along as they work, so you always know what is next.

  • Cards follow the agent doing them
  • Click or drag to move things yourself
  • Always see what is next

Check in from your phone

Open UnderGlow in your phone's browser, from anywhere. See progress, answer an agent, or approve a change without going back to your desk.

  • Same account, same app
  • Nothing to install on your phone
  • Stay in control of every project
